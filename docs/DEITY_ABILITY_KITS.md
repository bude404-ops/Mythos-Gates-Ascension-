# Mythos Gates: Ascension — Deity Ability Kits

## Design Principle
Every deity is a FULL SOLO combatant. The role changes HOW you fight through a dungeon, not whether you can clear it. Same dungeon = completely different playthrough per deity.

## Roles
- **Defender** — Methodical, unkillable, room-by-room
- **Disruptor** — Bait, fake, steal tempo, punish recovery
- **Sustain** — Outlast via lifesteal, regen, endurance
- **Assassin** — Stealth, dodge, burst, execute
- **Battery** — Spam abilities, resource gen, combo chains
- **Breaker** — Crack defenses, armor-break, stagger
- **Artillery** — Positioning-based, devastating lines
- **Controller** — Terrain weapon, hazards, pathing
- **Guardian** — Protect objectives while fighting

## Roster (28 deities, 4 per faction, 7 factions)

See Telegram DM messages for full ability kits. Each deity has: 1 Passive + 3 Active Abilities + 1 Ultimate.
