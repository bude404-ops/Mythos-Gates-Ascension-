## STAT LEGEND

| Stat | Abbrev | Description |
|------|--------|-------------|
| HP | Health Points | Damage capacity before death |
| DEF | Defense | Damage reduction (%) |
| ATK | Attack | Base damage scaling |
| DE | Divine Energy | Ability resource pool |
| SPD | Speed | Movement + attack speed (1-10) |
| CRIT | Critical Rate | Critical hit chance (%) |

| REC | Recovery | HP regen per second |
