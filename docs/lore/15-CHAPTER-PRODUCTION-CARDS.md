# Chapter Production Cards — v0.4.0

The Dev Platform now includes a Chapter Detail route that joins each chapter into a single production-facing card.

Each card binds:

- Campaign context
- Map description, hazards, and objectives
- Chapter objectives and unlocks
- NPC witnesses and campaign threat pool
- Direct canon lore links
- Mission dialogue beats
- Campaign sibling chapter navigation

The goal is to make each chapter reviewable as a production unit instead of scattering canon, map, and script context across separate screens.
