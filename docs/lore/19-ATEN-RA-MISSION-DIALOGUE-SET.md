# Aten Ra Mission Dialogue Set — v0.5.0

The dialogue set supports all 40 Aten Ra missions with concise mobile-friendly beats:

- Mission Intro
- Enemy Introduction
- Mid-Battle
- Victory
- Defeat
- Codex

Tone rules:

- Titans speak with restraint.
- Directors give production-facing clarity.
- No modern slang.
- No comedic one-liners.
- No contradiction of Titan-only playable structure.
- Elite dialogue acknowledges pressure without becoming a repeat of Normal.
