# KAMI Mission Dialogue Set — v0.5.0

The dialogue set supports all 40 KAMI missions with concise mobile-friendly beats:

- Mission Intro
- Enemy Introduction
- Mid-Battle
- Victory
- Defeat
- Codex

Tone rules:

- Deities speak with restraint and faction-specific authority.
- NPC witnesses guide, warn, and pressure without commanding the deity.
- Threats speak with dread or law, never jokes.
- No modern slang.
- No comedic one-liners.
- Elite dialogue acknowledges pressure without becoming a repeat of Normal.
- Faction-specific tone: spare precision, ritual consequence
